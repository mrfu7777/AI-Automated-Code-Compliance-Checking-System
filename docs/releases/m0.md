# M0 Architecture Baseline

- Version: 0.1.0
- Status: Complete
- Date: 2026-09-04

## Outcome

M0 establishes the engineering and domain foundation that later milestones extend. It intentionally does not implement OCR, model integration, fire-code rules, or customer workflows.

## Delivered

- React 19 and TypeScript application shell
- FastAPI v1 API with health and contract endpoints
- Structured error and request ID contracts
- Celery worker configuration
- PostgreSQL, Redis, MinIO, API, worker, and web Docker Compose services
- SQLAlchemy models for the long-lived domain entities
- Initial Alembic migration for an empty database
- Pydantic contracts for evidence, project facts, clauses, rules, and check results
- Evidence and missing-data safety validation
- OpenAPI snapshot
- Architecture decision records and initial ER diagram
- Backend linting, strict type checking, tests, and coverage gate
- Frontend linting, component test, and production build
- GitHub Actions validation, including full-stack startup
- Repository rules that exclude private project material and secrets

## Stable contracts for M1

M1 must extend, rather than replace:

- FileVersion for immutable uploaded files
- Job for asynchronous progress and retry state
- Evidence for source location
- the /api/v1 namespace
- the standard error envelope
- Alembic migrations
- the Docker Compose service topology
