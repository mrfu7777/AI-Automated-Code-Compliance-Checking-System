## Contract notes

- UUID identifiers are generated by the application.
- Source files and published rule packages are immutable versions.
- Flexible extraction payloads use JSON only behind typed Pydantic contracts.
- Timestamps are stored in UTC.
- Deletion of regulated records is represented through lifecycle state, not destructive cascading.
